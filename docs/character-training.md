# 推奨育成ルート

入力Excelはキャラごとに1シート。B列は最短育成、C列は完熟育成。
完熟育成の1部2部はC列が1周目、D列が2周目、E列が3周目。3部はC列だけを使う。
5行目で推奨ルートを4主人公から1人選択する。
初級職・中級職・上級職は1部2部、最上級職・神将職は3部として表示する。
兵種は各区分の上から順に入力し、空欄は表示しない。同じ区分の行をコピーして挿入すると枠を増やせる。
「入力規則」シートの兵種は区分ごとに縦並び。候補は100行目まで追加可能。

保存したExcelを反映するコマンド：

```powershell
python -B scripts/sync-character-training.py "入力Excelのパス.xlsx"
```

全キャラ分を検証してから `data/character-training.json` と個別ページを更新する。
入力規則候補は検証にのみ使い、未入力の兵種を掲載しない。
推奨データ自体は空欄で開始する。Excelの保存だけではサイトは更新されない。
JSONからページだけ再生成する場合はExcelパスを省略する。
