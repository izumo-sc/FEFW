# 所持武器管理の兵種・武器種

- 兵種名・ID・区分：既存の `dist/growth-data.js` の59兵種。
- 使用可能武器種：2026-09-26に保存した `work/class_growth_20260926/skill_pages/*.html` の「使用可能技能」で `_able` と示された剣術・槍術・斧術・弓術・格闘術を使用。各兵種の参照URLは `classes-data.js` の `source` に記録。資格試験の要求技能 (`class-requirements.js`) からは推定しない。
- 武器ID：既存の錬成資料 `forging-data.js` の26武器。元動画 `2026-10-14 00-54-24.mkv` の武器アイコン・技能表示を参照。
- サラマンダー・ツェルベルスは魔法攻撃を行う携帯火器だが、武器種の判定は格闘術（籠手）。保存フレーム108・115を確認。補助照合：<https://game8.jp/fe-banshisenko/819467>、<https://gamewith.jp/fefw/580457>。

兵種が未選択の場合は全武器を自由に選択できる。兵種を選択・変更した時は、装備できない武器のみ外す。兵種の選択を解除した時は所持武器を保持する。キャラ枠を移動した時は兵種と所持武器も一緒に移動する。武器の入れ替えは移動元・移動先の両兵種で判定し、未選択側は武器種を制限しない。
