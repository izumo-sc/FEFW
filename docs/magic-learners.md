# 個別キャラの習得表とスキル・戦技・魔法の更新

編集元は `data/character-learnsets.json`。
各キャラの `skills` 内で、技能・レベルの配列へ修得する名称を文字列で入れる。
配列のレベルがそのまま表示先になる。空配列は個別キャラの表では空欄、一覧へは表示しない。

編集後に `python scripts/sync-character-skills.py` を実行すると、全キャラの習得表とスキル・戦技・魔法の両方を更新する。
この処理はExcelを読まず、共通JSONとコード内の共通技能を参照する。JSONを保存しただけでは公開用ファイルは変わらないため、変更後に実行する。
個別キャラの表はキャラIDで対応づけ、成長率・スカウト条件などは変更しない。
一覧は全12技能からスキル・戦技・魔法ごとに修得者とレベルを逆引きし、公開用の `learners-data.js` を更新する。
剣術・槍術・斧術・弓術・格闘術・黒魔術・白魔術のLv1～5と深奥は、JSONに記載せず `scripts/common_skill_learnsets.py` で定義する。Lv1～5は順にD＋・C＋・B＋・A＋・S、深奥はS＋。個別キャラ表の生成時に共通定義を合成し、同じセルに個別の魔法がある場合は両方表示する。習得者一覧にはLv系・深奥を表示しない。指揮術と移動系には追加しない。
個別キャラへのリンクにはJSONのキャラIDを利用する。

手動入力ブックから魔法を更新するときは `python scripts/import-manual-magic.py "手動入力ブックのパス.xlsx"` を実行する。
キャラ名と一致するシートの黒魔術・白魔術の実入力セルのみを読む。入力規則シートや照合ブックの候補は使わない。
魔術Lv・深奥を除く名称を取り込み、末尾の（A＋）等はその技能レベルへ移す。複数名称は個別に扱い、重複を除く。
この取り込みはJSONの黒魔術・白魔術のみを置き換え、個別キャラ表と一覧も更新する。元のExcelファイルは変更しない。

魔術以外の10技能を取り込む場合は、同じコマンドの末尾に `--non-magic` を付ける。この場合は黒魔術・白魔術を保持し、他の技能の実入力セルを取り込む。Lv系・深奥の除外、ランク注記の移動、両画面の更新は同様に行う。
